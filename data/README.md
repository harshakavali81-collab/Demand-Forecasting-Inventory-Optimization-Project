# Bundled demonstration data

`raw/demo_sales.csv` and `raw/demo_products.csv` are deterministic synthetic inputs generated by `src/demand_inventory/data.py`; names, sales, stock, supplier assumptions, and outcomes are illustrative.

`example_outputs/` contains the outputs from running the full 30-day forecast and inventory workflow with the default model selection against the bundled sample data. Regenerate them from the project root:

```powershell
python -m demand_inventory.cli --horizon 30 --output-dir data/example_outputs --raw-dir data/raw
```

These sample outputs are versioned to make the repository and downloadable ZIP immediately explorable. Do not interpret them as real sales, forecast benchmarks, purchasing advice, or business impact.
