# Portfolio project: Demand Forecasting & Inventory Optimization

## Overview

A portfolio-grade reference implementation showing a transparent flow from transaction data to demand forecast and inventory review. Its demo data is synthetic.

## What it demonstrates

- Reusable Python modules for validation, feature engineering, forecasting, and inventory formulas.
- Chronological baseline comparisons with MAE, RMSE, and WAPE.
- An interactive Streamlit dashboard and read-only FastAPI service.
- PostgreSQL starter schema, test suite, Docker setup, and project documentation.

## Run locally

See the repository README for environment setup, CLI, tests, and dashboard commands. The sample data does not represent actual company results.
